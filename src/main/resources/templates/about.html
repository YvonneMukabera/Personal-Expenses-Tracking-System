About This System

Smart Personal Finance

Track income, spending, and balance in FRW with confidence

This system gives users a clear, secure way to record expenses, manage monthly income, and compare financial performance across months and years.

Expenses Income Dashboard FRW

Project Scope

  • Secure account registration and login.
  • Expense records with title, category, quantity, unit cost, date, and total.
  • Monthly and yearly dashboard filters with histogram charts.
  • Income, expenses, and balance summaries in Rwandan francs.

Database Structure

The active backend model tables are aligned with the project architecture.

Model Table Purpose
User users Stores login and profile details.
Expense expense Stores spending records linked to a user.
Income income Stores monthly income linked to a user.
