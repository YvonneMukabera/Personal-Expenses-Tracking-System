About the System

System Overview

  • • Purpose: Centralized tracking for daily financial transactions.
  • • Goal: Monitor spending habits and maintain a healthy balance.
  • • Architecture: Powered by Spring Boot 3.x and Spring Data JPA.
  • • UI Engine: Dynamic server-side rendering via Thymeleaf.

Core Capabilities

  • • Data Management: Full CRUD operations (Add, View, Edit, Delete).
  • • Visualization: Real-time financial charts powered by Chart.js.
  • • Efficiency: Integrated pagination for fast record browsing.
  • • Calculations: Automatic unit-cost and total balance aggregation.
